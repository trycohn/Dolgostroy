# ДОЛГострой

## Команда

- Горенков Климентий Никитович
- Марков Илья Любомирович
- Винокуров Артём Янович
- Одибоев Имран Фарухжонович

## Жанр

Комедийная RPG с пошаговыми боями.

## Описание

Игрок управляет коллектором, исследует город, встречает
должников, участвует в боях и развивает персонажа.
